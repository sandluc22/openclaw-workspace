# Procedimientos de Contabilidad

## Estructura
Cada procedimiento tiene:
- **Responsable**: quién lo ejecuta
- **Frecuencia**: diario / semanal / mensual / trimestral / anual
- **Pasos**: lista detallada
- **Documentos asociados**: facturas, informes, etc.

---

## 📅 Calendario fiscal general

### Modelo 303 — IVA Trimestral
- **Responsable**: [nombre]
- **Frecuencia**: Trimestral (abril, julio, octubre, enero)
- **Plazo**: hasta el 20 del mes siguiente al trimestre
- **Pasos**:
  1. Recopilar facturas emitidas y recibidas del trimestre
  2. Calcular IVA repercutido - IVA soportado
  3. Presentar telemáticamente en AEAT
  4. Guardar justificante de presentación

### Modelo 130 — IRPF Trimestral (autónomos)
- **Responsable**: [nombre]
- **Frecuencia**: Trimestral
- **Plazo**: hasta el 20 del mes siguiente al trimestre
- **Pasos**:
  1. Calcular rendimiento neto del trimestre
  2. Aplicar retenciones y pagos fraccionados
  3. Presentar en AEAT
  4. Registrar pago

### Modelo 390 — Resumen Anual IVA
- **Responsable**: [nombre]
- **Frecuencia**: Anual (enero)
- **Plazo**: hasta el 30 de enero
- **Pasos**:
  1. Revisar todos los trimestres del año
  2. Cruzar datos con el libro registro
  3. Presentar declaración-resumen

### Modelo 100 — Renta
- **Responsable**: [nombre]
- **Frecuencia**: Anual (abril-junio)
- **Plazo**: según calendario AEAT
- **Pasos**:
  1. Recopilar datos fiscales del año
  2. Revisar borrador
  3. Confirmar o modificar y presentar

## 📋 Gestión de facturación

### Emisión de facturas
- **Responsable**: [nombre]
- **Frecuencia**: Según ventas
- **Pasos**:
  1. Crear factura con datos fiscales correctos
  2. Enviar al cliente
  3. Registrar en libro de facturas emitidas
  4. Archivar copia

### Control de facturas pendientes
- **Responsable**: [nombre]
- **Frecuencia**: Semanal
- **Pasos**:
  1. Revisar facturas emitidas no cobradas
  2. Enviar recordatorio a clientes morosos
  3. Actualizar estado en el sistema

---

## 💰 Gestión de cobros y pagos

### Pagos a proveedores
- **Responsable**: [nombre]
- **Frecuencia**: Según vencimientos
- **Pasos**:
  1. Revisar facturas recibidas pendientes
  2. Autorizar pago
  3. Ejecutar transferencia
  4. Registrar pago y archivar

### Conciliación bancaria
- **Responsable**: [nombre]
- **Frecuencia**: Mensual
- **Pasos**:
  1. Descargar movimientos bancarios
  2. Cotejar con facturas emitidas y recibidas
  3. Identificar discrepancias
  4. Ajustar y cuadrar saldos

---

## 🏢 Sociedades

### Libro registro
- **Responsable**: [nombre]
- **Frecuencia**: Diario/según operaciones
- **Pasos**:
  1. Registrar todas las facturas emitidas
  2. Registrar todas las facturas recibidas
  3. Registrar ingresos y gastos en efectivo

### Cuentas anuales
- **Responsable**: [nombre]
- **Frecuencia**: Anual
- **Plazo**: 3 meses desde cierre del ejercicio
- **Pasos**:
  1. Preparar balance de situación
  2. Preparar cuenta de pérdidas y ganancias
  3. Preparar memoria
  4. Depositar en el Registro Mercantil
