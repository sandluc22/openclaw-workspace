# 🚀 Fiverr — Gestión de proyectos

Panel de control de todos los trabajos que hagas en Fiverr: seguros, asesoría financiera, contabilidad, lo que venda.

---

## 📂 Estructura

| Carpeta | Para qué |
|---------|----------|
| **clientes/** | Una carpeta por cada proyecto. Briefing, conversaciones, avances |
| **plantillas/** | Respuestas rápidas, propuestas, informes, mensajes tipo |
| **entregas/** | Archivos finales listos para enviar al cliente |
| **recursos/** | Material de apoyo: logos, guías, PDFs de referencia |
| **facturas/** | Historial de cobros, extractos, comprobantes |
| **metrica/** | Estadísticas de pedidos, ingresos, valoraciones |
| **apps/** | Desarrollo de aplicaciones web, móviles o herramientas |

---

## 🧠 Cómo trabajar aquí

1. Llega un pedido → crear carpeta en **clientes/nombre-del-proyecto/**
2. Copiar plantilla de proyecto desde **plantillas/**
3. Trabajar los entregables en **entregas/**
4. Facturar y guardar copia en **facturas/**
5. Cuando termine, mover a **metrica/completados/** con resumen
